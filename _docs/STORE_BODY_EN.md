# ProjectE: EMC for The Undergarden

With this add-on, The Undergarden's materials gain EMC and can be used in ProjectE's transmutation system; without it, ProjectE cannot use them. Its values keep unusual block and item forms from becoming alternate EMC sources.

## What is valued

Hand-set EMC is placed on The Undergarden's core materials, while ProjectE derives the rest from the host mod's vanilla-type recipes.

Metal EMC lives on ingots, not on ores or raw chunks. The same metal can appear in depthrock, dreadrock, shiverstone, and tremblecrust; keeping every ore and raw-material form at zero prevents those four host rocks from becoming separate price entrances to one metal.

The depthrock variants that drop vanilla iron, gold, diamond, or coal are deliberately untouched. Changing them would alter vanilla's existing EMC band and, in turn, the prices expected by other content.

## Infuser conversions on 1.21.1

ProjectE learns EMC values by following vanilla-style crafting, smelting, stonecutting, smithing, and similar recipes. The Undergarden's Infuser does not use any of these recipe types, so ProjectE cannot see its outputs.

This add-on explicitly defines its four conversions: utheric cluster with rogdorium to utherium crystal; gronglet with rogdorium to rogdoric gronglet; gronglet with utherium crystal to utheric gronglet; and ancient root with rogdorium to denizen totem. Each value includes both the input and the catalyst because the Infuser consumes its catalyst.

These conversions are included only for 1.21.1; The Undergarden for 1.20.1 does not yet have an Infuser, so its version contains none.

## Items intentionally left without EMC

Carved gloomgourds have no EMC. Shearing a placed gloomgourd produces a carved gloomgourd and four gloomgourd seeds, so valuing both forms alike would create repeatable EMC from the seeds. Gloom-o-lanterns and shard-o-lanterns also have no EMC for that reason, matching vanilla jack-o-lanterns.

All cloggrum, froststeel, forgotten, and utherium tools, weapons, and armour have no EMC. Their durability and enchantments are item state that conversion should not erase or recreate.

## Music discs on 1.21.1

The Undergarden's five music discs already receive EMC through ProjectE's disc tag on Minecraft 1.20.1. On 1.21.1 they use the newer convention tag that ProjectE does not read, so this add-on assigns them 2,048 EMC each: the same tier as the vanilla discs ProjectE prices at 2,048.

## Requirements

- ProjectE is required.
- The Undergarden is required.
- Minecraft 1.21.1 on NeoForge, and Minecraft 1.20.1 on Forge, are supported.
- This is server-side data; clients do not need to install it.
